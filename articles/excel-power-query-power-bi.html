Excel, Power Query or Power BI? Choosing the Right Tools for AI-Powered FP&A

They aren't rivals. Here's how I decide which tool does which job, and where Python and AI fit in.

By Jamil Ur Rehman · 6 min read

"Which is better, Excel or Power BI?" I hear this question a lot, and I think it's the wrong one to ask.

FP&A today is less about producing spreadsheets and more about building a workflow: reliable data coming in, automated analysis in the middle, and better decisions coming out. Each tool owns a different part of that journey. Add AI and Python, and the repetitive parts shrink even further, leaving more time for the analysis that actually moves the business.

The short version

ToolWhat I use it forWhere AI helps
ExcelBudgets, forecasts, financial models, scenariosDrafting and explaining formulas, finding errors
Power QueryCleaning, combining and mapping raw dataWriting and fixing M code
Power BIDashboards, KPIs, budget vs actualWriting and debugging DAX, exploring trends
PythonHeavy processing, reconciliations, report automationWriting and maintaining scripts

1. Excel: where the thinking happens

Excel is still where I build budgets, forecasts, three-statement models and scenarios. Nothing beats it for flexible "what if" thinking: change one assumption and watch it flow through the P&L, the balance sheet and cash.

AI is a useful modelling partner. It can draft a tricky formula, explain one someone else wrote, or help find why a balance sheet won't balance. But it doesn't own the model. Every assumption and every output still gets checked by someone who understands the business.

Best for: financial modelling, forecasting, scenario analysis and detailed decision support.

2. Power Query: the end of copy-and-paste

A surprising amount of FP&A time disappears before any analysis starts: combining twelve monthly files, fixing account codes that changed, mapping several entities to one chart of accounts. Power Query does this once, then repeats it every month with a single click on Refresh.

When a step gets tricky, AI helps me write or fix the M code behind it. The result is a data preparation process that is documented, repeatable and identical every month.

Best for: data cleaning, consolidation, transformation and repeatable reporting.

3. Power BI: answering management's questions

Power BI turns clean data into interactive dashboards: revenue, EBITDA, budget variances, margins and working capital, for one entity or the whole group.

AI helps me write and debug DAX measures, and depending on the tools and licences available, built-in AI features can help users explore the data and summarise trends. But the real value isn't in the visuals. It comes from a sound data model, measures you can trust, and pages designed around the questions management actually asks. You can see this approach in my FP&A & Financial Performance Dashboard.

Best for: management reporting, KPI monitoring, multi-entity analysis and investigating performance.

4. Python and AI: when spreadsheets aren't enough

Some jobs outgrow spreadsheets: matching thousands of transactions, handling dozens of files, or calculations too complex to maintain safely in formulas. Python handles these comfortably. It processes the data, runs validation checks and writes the finished Excel report.

AI coding assistants make these scripts much faster to build and maintain. Once tested, the scripts run on their own inside approved company systems, so production financial data isn't sent to an AI model, as long as the workflow itself doesn't pass that data through other outside services. I've written more about this in Automating Financial Reporting with AI.

Best for: complex data processing, repeatable reconciliations, bespoke analysis and reporting automation.

How the tools work together

Here's what a practical AI-assisted FP&A workflow can look like:

  1. Power Automate collects incoming files and saves them to the right folders.
  2. Power Query or Python cleans, maps and validates the financial data.
  3. Power BI shows actual performance, trends and budget variances.
  4. Excel supports detailed modelling and scenario analysis.
  5. AI tools help with building code, fixing problems and interpreting results, within approved data-security boundaries.
  6. The analyst checks the outputs, digs into what's driving the numbers, and explains it to management.

Not every process needs all of these. I choose the combination based on data volume, how complex the process is, what the report needs to show, and the systems already in place.

The bottom line

Excel, Power Query and Power BI aren't competing for the same job. They solve different problems. Python extends what can be automated, and AI speeds up both the building and the analysis.

The real advantage doesn't come from any single tool. It comes from combining them with solid financial knowledge, reliable data and good judgement.

Use AI to speed up the work, automation to remove the repetition, and financial expertise to turn the results into better decisions.
